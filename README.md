# Дневник смен водителя

Мини-приложение: сервер на Express и мобильный веб-клиент, сверстанный под
телефон водителя. Показывает сводку по сменам за выбранный день (выручка,
комиссия, "на руки", разбивка наличные/карта), недельный график дохода,
список поездок и форму добавления новой поездки прямо из интерфейса.

## Запуск

```
npm install
npm start
```

Откроется сервер на `http://localhost:3000`.

## Тесты

```
npm test
```

## Что сделано

- `GET /api/trips?date=YYYY-MM-DD`: список поездок за день и сводка
- `GET /api/weekly?date=YYYY-MM-DD`: доход за 7 дней, для недельного графика
- `POST /api/trips`: добавление поездки с валидацией (сумма больше 0, конец позже начала) и защитой от дублей по `id`
- Клиент: сводка за день, недельный график (тап по дню переключает дату), список поездок, переключение дней стрелками или календарём, форма добавления поездки (bottom sheet, с автоматическим расчётом комиссии 15%)
- Тесты: расчёт сводки (`test/summary.test.js`), защита от дублей и невалидных данных (`test/store.test.js`), расчёт дат для недельного графика (`test/weekly.test.js`)
- CI: тесты гоняются автоматически на каждый push и pull request (`.github/workflows/test.yml`)

## Как использовался ИИ

Сервер на Express, клиент и тесты писал Claude Code. Я формулировала
требования и дорабатывала задание по ходу: попросила сделать интерфейс
под телефон водителя, добавить недельный график дохода, форму добавления
поездки прямо в интерфейсе и автотесты через GitHub Actions, того, чего
в условии не было, чтобы задание показывало не только рабочий код, но и
продуктовое мышление.

На каждом шаге сама проверяла результат в браузере: переключение дней,
добавление поездки, мобильную версию. При такой проверке нашёлся баг:
новые поездки сохранялись в UTC, а исходные данные были в местном
времени (+05:00), из-за чего время на экране съезжало на 5 часов.
Разобралась, в чём дело, и попросила исправить это несоответствие
форматов.

Все 7 тестов (расчёт сводки, защита от дублей и невалидных данных,
расчёт дат для графика) проходят, CI на GitHub Actions зелёный.
