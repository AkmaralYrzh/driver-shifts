# Дневник смен водителя

Мини-приложение: сервер на Express + мобильный веб-клиент (сверстан под
телефон водителя). Показывает сводку по сменам за выбранный день (выручка,
комиссия, "на руки", разбивка наличные/карта), недельный график дохода,
список поездок и форму добавления новой поездки прямо из интерфейса.

## Запуск

```
npm install
npm start
```

Откроется сервер на `http://localhost:3000`.

## Тесты

```
npm test
```

## Что сделано

- `GET /api/trips?date=YYYY-MM-DD` — список поездок за день + сводка
- `GET /api/weekly?date=YYYY-MM-DD` — доход за 7 дней, для недельного графика
- `POST /api/trips` — добавление поездки с валидацией (сумма > 0, конец позже начала) и защитой от дублей по `id`
- Клиент: сводка за день, недельный график (тап по дню переключает дату), список поездок, переключение дней стрелками/календарём, форма добавления поездки (bottom sheet, с автоматическим расчётом комиссии 15%)
- Тесты: расчёт сводки (`test/summary.test.js`), защита от дублей/невалидных данных (`test/store.test.js`), расчёт дат для недельного графика (`test/weekly.test.js`)
- CI: тесты гоняются автоматически на каждый push/PR (`.github/workflows/test.yml`)
